## The instruction the model followed

> Review this zoning code for rules that limit how much housing can be built or how affordable it can be.
> For each rule: quote the exact text, give its section, classify it (density, parking, process, other),
> and say whether it restricts or enables housing. Do not report any rule that is not in the text.

## What verification changed

The first scan used the 2018 manual. Checking the current code showed a 2022 amendment (Ord. 14065)
changed transit-area parking reductions from an administrative Waiver to an **Exception with City
Commission approval** (a public hearing) outside downtown and other designated areas — stricter than
the 2018 text. The 100%-reduction rule for small buildings now needs the same approval outside those areas,
so it no longer counts as a general enabler.

## One-line takeaway for the deck

Our AI scan of Miami's current zoning code found that apartments must provide 1.5 parking spaces per unit,
and that outside downtown, cutting that near transit requires a City Commission hearing — and isn't allowed
at all within 500 feet of single-family zones.

## Limits to state honestly

- Article 4 was read through Zoneomics, a third-party code host. The official code is the City's
  *Miami 21 Code, as amended*; spot-check the key lines there if possible.
- Covers the **City of Miami only**; the metro includes many other cities and three counties.
- **State law may override some local rules** for qualifying affordable projects (e.g., Florida's 2023
  Live Local Act). Check before claiming a rule blocks affordable housing.
- The scan shows **what the rules say**, not how much housing they prevented.
